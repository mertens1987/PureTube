# ⬇️ Installation

In order to use ReVanced on your Android device, PureTube must be installed.

## ✅ Installation steps

1. Download the latest version of PureTube at [revanced.app/download](https://revanced.app/download) or from [GitHub releases](https://github.com/ReVanced/puretube/releases/latest)
2. Install PureTube
